# Утка

Утка — приложение для macOS: островок у верхнего края экрана, который открывается наведением курсора на верхнюю кромку и держит под рукой то, чем пользуешься каждый день — временные файлы, историю буфера обмена, заготовленные фразы и перевод, без сторонних сервисов и подписок.

Панель выезжает на том мониторе, где сейчас курсор. Увод курсора её прячет. В Dock утка не сидит, только иконка в строке меню.

## О проекте

Утку пишет [@Goncharov108](https://github.com/Goncharov108). Код и обновления лежат в этом открытом репозитории, ветка `main`.

## Четыре раздела

- **Полка** — файлы под рукой и новые снимки экрана. Карточку можно вытащить.
- **Буфер** — последние скопированные тексты. Клик возвращает текст в буфер, крестик убирает строку. Картинки и файлы в историю не попадают.
- **Заготовки** — фразы и файлы, которые достаёшь часто, на отдельных вкладках. Клик по фразе копирует её; шеврон раскрывает заметку на всё окно, там текст можно выделить и скопировать частично. Файл вытаскивается и остаётся в списке.
- **Перевод** — английский и русский своим офлайн-движком ([utka-translate](https://github.com/utka-apps/utka-translate)), без ключей, без аккаунтов и без сети. Пишешь в одно поле, перевод падает в другое. Один раз нужно скачать движок (≈150 МБ) кнопкой в настройках; после этого текст не покидает Мак.

## Что нужно

- macOS 13.3 или новее. Для перевода нужна Apple Silicon (движок пока собран только под arm64).
- [Command Line Tools](https://developer.apple.com/xcode/resources/): `xcode-select --install`

Скрипт собирает Intel и Apple Silicon в один `Utka.app`. Если какая-то архитектура на этой машине не собралась, скрипт напишет «сборка … пропущена». Тогда на Маке другого типа понадобится Rosetta.

## Сборка и запуск

При первой сборке скрипт один раз создаёт в связке ключей сертификат **Utka Local** и им подписывает приложение. Если macOS спросит пароль, это пароль входа на этот Мак. Сертификат лучше не удалять: с одной и той же подписью разрешение на запись экрана сохраняется после пересборки. Повторная сборка сертификат не пересоздаёт, только подписывает заново.

Из папки репозитория:

```bash
bash scripts/build-app.sh
open Utka.app
```

`Utka.app` появляется рядом со скриптом и в git не входит. После сборки в строке меню — белая утка. В Finder у `Utka.app` та же утка на чёрном квадрате.

Запуск при входе в систему: Системные настройки → Основные → Объекты входа → «+» и выбрать `Utka.app`.

Выход — пункт **Выход** в меню утки. Переключатель **Включена** прячет жест до следующего включения. **Показать** вытаскивает островок, не дожидаясь курсора на кромке; закрывается клавишей Escape. Клик по утке на островке открывает настройки: тот же жест, короткие подсказки, языковые пакеты перевода и проверка обновлений.

## Первый запуск

1. Открыть `Utka.app`. Иконка в меню есть — островок ещё спрятан.
2. Подвести курсор к верхней кромке по центру экрана и подержать долю секунды. Островок выезжает сверху. На втором мониторе — к кромке этого монитора.
3. Снимок области — кнопка с фотоаппаратом на верхней полосе островка. macOS спросит доступ **Запись экрана** (Системные настройки → Конфиденциальность и безопасность → Запись экрана). После разрешения утка перезапускается сама и открывает крестик выбора области. Без этого доступа снимок не запускается: в кадр попали бы только обои.
4. Если macOS спросит доступ к папке **Рабочий стол**, его стоит дать. Утка смотрит стол, чтобы забрать снимок, который система ещё положила туда по старому пути.

Перевод: настройки утки → «Перевод» → «Скачать». Файл проверяется по контрольной сумме SHA-256 до распаковки; если сумма не сошлась, установка отменяется. Пока движок не скачан, под полями перевода будет подсказка. Системные «Языки перевода» и «Переводчик» Apple не нужны и не используются.

## Куда деваются снимки экрана

После первого запуска утка переназначает снимки всей системы, не только свою кнопку:

- новые снимки (Cmd+Shift+3, Cmd+Shift+4 и кнопка на островке) пишутся в `~/Library/Application Support/Utka/Shots`;
- плашка миниатюры в углу экрана отключается;
- файл со стола с именем «Снимок экрана…», `Screenshot…` или `Screen Shot…` утка переносит в ту же папку;
- карточка появляется на полке. Удаление карточки своего снимка стирает и файл.

Чужой файл, который просто бросили на полку, при удалении карточки с диска не удаляется. Файл из заготовок тоже остаётся на месте.

Вернуть снимки на рабочий стол и плашку в углу:

```bash
defaults delete com.apple.screencapture location
defaults delete com.apple.screencapture show-thumbnail
killall screencaptureui
```

Пока утка запущена, при следующем старте она снова поставит свою папку.

## Не работает снимок

Если переключатель «Запись экрана» включён, а снимок не идёт, macOS могла запомнить другую подпись. Сброс и повторный запрос:

```bash
tccutil reset ScreenCapture dev.goncharov.utka
```

Потом снова открыть утку и нажать кнопку снимка. Если доступ так и не появился, утка покажет окно и предложит открыть Запись экрана.

## Звук

Виртуальный выход «Утка звук» — необязательный плагин: файл `/Library/Audio/Plug-Ins/HAL/UtkaAudio.driver`. Сборка его **не ставит**. Он нужен только ради ползунка громкости на мониторе без своего регулятора; ставится кнопкой в настройках «Звук» (тумблер по умолчанию выключен), и только тогда macOS один раз спросит пароль администратора. Отдельный релиз плагина ещё не опубликован, поэтому кнопка пока ответит «Файл ещё не опубликован»; те, у кого драйвер уже стоит, продолжают им пользоваться. При выключенном тумблере устройство скрыто из меню звука macOS.

Ползунок на островке ведёт громкость через этот выход, а играет выбранное железо. Без плагина островок, полка, буфер, заготовки, перевод и снимок работают. Маршрут звука просто не включается.

Снять плагин и перезапустить системный звук:

```bash
sudo rm -rf /Library/Audio/Plug-Ins/HAL/UtkaAudio.driver
sudo killall coreaudiod
```

`coreaudiod` система поднимает сама. После замены плагина звук тоже нужно перезапустить, иначе в памяти останется старый драйвер.

## Где лежат данные

Только на этом Маке, в `~/Library/Application Support/Utka/`. В репозиторий не входят.

| Файл | Что это |
| --- | --- |
| `shelf.json` | Карточки полки |
| `clipboard.json` | История буфера |
| `presets.json` | Заготовки |
| `Shots/` | Файлы снимков экрана |

Фразу можно дописать в `presets.json` и сохранить. Утка подхватит файл сама:

```json
{
  "id": "mail",
  "kind": "text",
  "title": "Почта",
  "body": "you@example.com"
}
```

Файл проще бросить на раздел «Заготовки».

## Сборка ещё раз

Поведение жеста и разрешения привязаны к подписи **Utka Local**, не к папке, откуда открыт `.app`. После правок кода достаточно снова выполнить `bash scripts/build-app.sh` и открыть приложение. Старый процесс сначала завершить через **Выход**: пока он работает, вторая утка сразу закрывается.

Перед сборкой скрипт копирует текущий `Utka.app` в `~/Library/Application Support/Utka/PreviousUtka.app`: эту копию ставит обратно кнопка «Вернуть предыдущую». Сборка во второй папке с кодом не должна её затирать:

```bash
UTKA_NO_PREVIOUS=1 bash scripts/build-app.sh
```

Если одна архитектура не собралась, скрипт пишет «сборка … пропущена» и собирает утку из другой. Для выпуска так нельзя: с `UTKA_RELEASE=1` скрипт в этом случае завершается с ошибкой.

Проверка геометрии зоны наведения без окна:

```bash
Utka.app/Contents/MacOS/Utka --self-check
```

В конце строка `SELF-CHECK OK`.

## Убрать с Мака

1. **Выход** в меню.
2. Удалить `Utka.app`.
3. По желанию удалить `~/Library/Application Support/Utka` — вместе с полкой, буфером, заготовками и снимками.
4. Если ставился выход «Утка звук», снять плагин командами из раздела «Звук».
5. Если снимки экрана всё ещё уходят в папку утки, вернуть системные настройки командами из раздела выше.
6. Сертификат **Utka Local** в Связке ключей можно удалить, если приложение больше не нужно. Пока он есть, повторная сборка не спрашивает создание заново, и разрешение записи экрана не слетает.
