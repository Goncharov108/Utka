# Утка

Островок у верхнего центра любого монитора. Курсор задерживается там около пятой доли секунды — панель открывается на этом экране. Уход курсора её закрывает.

Четыре раздела:

- **Полка** — временные файлы и новые скриншоты. Карточку можно вытащить на стол.
- **Буфер** — последние тексты, которые копировал. Клик возвращает текст в буфер, крестик удаляет строку.
- **Заготовки** — свои фразы, адреса, ссылки и файлы, которые достаёшь часто. Клик по фразе копирует её. Файл вытаскивается и остаётся в списке.
- **Перевод** — русский и английский через системные «Команды», без ключей и без списаний.

Личные записи лежат только на маке, в `~/Library/Application Support/Utka/`: `shelf.json`, `clipboard.json`, `presets.json`. В репозиторий они не входят.

Фразу можно дописать руками в `presets.json`:

```json
{
  "id": "mail",
  "kind": "text",
  "title": "Почта",
  "body": "you@example.com"
}
```

Файл проще бросить на раздел «Заготовки». Удаление записи сам файл на диске не трогает.

## Сборка

Нужны Command Line Tools и macOS 13.3 или новее. Перевод рассчитан на macOS 15.

```bash
bash scripts/build-app.sh
open Utka.app
```

Иконка в строке меню включает и выключает жест. В Dock утка не показывается.
