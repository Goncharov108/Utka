# Как предлагать правки

Общий код — репозиторий `utka-apps/utka`, ветка `main`.

1. Забери свежий `main`.
2. Сделай свою ветку от него.
3. Открой запрос на слияние в `main`.
4. Вливает владелец репозитория. Прямой push в `main` не используй.

Личные копии репозитория сами не обновляются. Перед правками сверься с общим `main`, чтобы не разойтись.
